# Trip Landing Bashu Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retheme `/trip` landing page brand and hero/form CTAs from TripStar / 旅途星辰 to 蜀韵智游 (Chengdu / Bashu positioning) across zh / en / ja.

**Architecture:** Copy lives in `src/trip/i18n/locales/{zh,en,ja}.json`. Replace hardcoded `TRIPSTAR` / `TripStar` in `LandingView.vue` and trip `NavBar.vue` with `t('app.brand')`. Grep-clean remaining user-visible TripStar / 旅途星辰 strings under `src/trip` that appear on landing or result footers.

**Tech Stack:** Vue 3 + vue-i18n (trip package), JSON locales; no API changes.

## Global Constraints

- Positioning: Chengdu / Bashu only — brand **蜀韵智游** / EN **Shu Journey** / JA **蜀韻スマート旅**.
- Verbatim zh hero subtitle: `把巴适日子，排成一条天府路`
- Verbatim zh submit: `生成我的成都行程`
- Hero `h1` must use i18n — no hardcoded `TRIPSTAR`.
- Do not change form field names, validation rules, or API payloads.
- Do not change main-site `src/locales/*/trip` HomeView block unless asked.
- Skip git commits unless the user explicitly asks.
