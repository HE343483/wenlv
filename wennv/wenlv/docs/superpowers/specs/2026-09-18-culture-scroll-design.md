# 文明脉络 · 平面透视建筑长卷（展卷漫游）

**日期：** 2026-09-18  
**范围：** 公开首页「文明脉络」板块（替换现有竖向时间线卡片）  
**状态：** 设计已口头确认，待用户审阅本 spec 后进入实现计划

---

## 1. 背景与目标

现有「文明脉络」为竖向点线 + 文案卡片，偏资料表，缺少沉浸感。目标改为：**一幅可展读的成都建筑历史长卷**——时间融进画面（如《清明上河图》），并以横版游戏式前后景分层 + 小人跟镜，形成「人在画中走、时代在眼前过」的体验。

**成功标准：**
1. 主画面是连续艺术长卷，而非抽象时间轴 + 插图叠加。
2. 远/中/近景分层；建筑从古代形态渐变到现代。
3. 用户滚动或拖动展卷；小人跟镜头，呈行走感。
4. 视觉为 **2D 平面插画风格，允许透视（近大远小）**；**不使用 3D 模型 / WebGL 场景 / 立体网格**。
5. 可点击画中标志建筑查看短注（沿用现有 timeline 文案）。
6. `prefers-reduced-motion` 与窄屏有可用降级。

## 3. 视觉语言

- **线稿 / 简笔黑线**为主，纸色或浅米底，呼应站点 cream 表面；可少量金点缀热点，不抢画面。
- **平面插画**：色块与描边；可有透视灭点、近景放大、远景缩小；**禁止** Three.js / 真实 3D mesh / 伪 3D 旋转立方。
- **三层：**
  - **远景：** 山影、淡天际，横移最慢
  - **中景：** 主体建筑长卷（古→今），横移中速
  - **近景：** 路面、桥栏、树丛，横移最快
- **小人：** 平面剪影或简笔人物，固定在视口偏下约 1/3～中线处；镜头横移时播放走步循环，方向随滚动方向切换。

## 5. 交互与技术结构

### 5.1 组件

新增例如 `CultureScroll.vue`（名称实现时可定），由 `HomeView` 文明脉络区挂载。

### 5.2 展卷驱动

- 进入板块：`pin` 舞台至视口；竖向滚动映射为长卷 `translateX`（GSAP ScrollTrigger 或等价轻量实现）。
- 同时支持指针 **水平拖拽** 微调/移动端滑动（与 scrub 进度同步，避免打架）。
- 进度 `0→1` 驱动：各层不同速率的 `x`、小人朝向与步态、可选当前区段标题淡入。

### 5.3 热点

- 中景建筑上放置不可见或极轻的 hit 区；点击弹出浮层：时代名 + 一句描述（中英随语言 store）。
- 不出现贯穿全宽的粗时间轴；若需方位，仅用画跋式短落款或底部极淡年代字。

### 5.4 资源

- 优先 **内联 / 外链 SVG** 分层资源，放于 `public/images/culture-scroll/` 或 `src/assets/culture-scroll/`。
- 首期可用简化几何拼出可读天际；后续可替换为更精细插画而不改交互壳。

### 5.5 无障碍与降级

- `prefers-reduced-motion: reduce`：取消 pin 强 scrub，改为普通横向 `overflow-x: auto` 滑看；小人静态。
- 小屏：缩短卷长或降低层复杂度；拖滑为主。
- 热点按钮需可键盘聚焦；浮层可 Esc 关闭。

## 6. 明确不做

- Three.js / Babylon / 真 3D 建筑漫游
- 键盘 WASD 操作角色（本期选 B；可作后续增强）
- 抽象点线时间表作为主视觉
- 跑酷跳跃、战斗等强游戏机制
