# 文明脉络 · 长卷内嵌时间轴（常显卡片）

**日期：** 2026-09-18  
**范围：** `CultureScroll.vue` 中景层信息架构；替换可点击热点 + 弹层  
**状态：** 口头确认（文案完整度 C、方案 1）；待用户审阅本 spec 后进入实现计划  
**前置：** [2026-09-18-culture-scroll-design.md](./2026-09-18-culture-scroll-design.md)

---

## 1. 背景与目标

长卷主视觉已就位（黄蓝山水底 + 黑线插画），但时代信息仍依赖「点热点 → 弹层」。用户要求在画面中部加一条 **从左到右的时间轴**，卡片 **无需点击**，直接在轴的上方或下方展示完整文案；轴上标出对应时间。

**成功标准：**
1. 中景存在一条横贯长卷的细时间轴，垂直位置约在视口 **55%～60%**（对齐用户标注的中线）。
2. 每个文明区段有一个节点：轴上显示 `period`（时间），卡片显示完整 `era` + `period` + `desc`（中英随语言 store）。
3. 卡片奇偶交替置于轴上 / 轴下；不可点击、无弹层。
4. 轴与卡片挂在中景层，随展卷同速横移（空间 = 时间）。
5. 移除原热点按钮与 dialog/scrim；左下角画跋（当前区段）可保留。
6. `prefers-reduced-motion` / 窄屏下轴与卡片仍可读。

## 2. 方案选型（已确认）

| 项 | 选择 |
|----|------|
| 布局 | **方案 1：中景内嵌轴**（非视口固定轴） |
| 卡片文案 | **C：完整**（与现有 segment 字段一致） |
| 交互 | **常显、不可点**；去掉热点点击与浮层 |

不采用：视口钉死时间轴、保留点击热点另加装饰轴。

## 3. 视觉与布局

### 3.1 时间轴

- 一条细墨色横线，贯穿中景世界宽度（与 mid layer 同宽）。
- 垂直：`top: 56%` 左右（实现时可微调为 CSS 变量）。
- 风格：低对比描边，不抢黑线插画；节点为小圆点（可沿用站点金点缀，但弱于旧热点脉冲）。

### 3.2 节点与卡片

- 水平位置：沿用 `CULTURE_SCROLL_HOTSPOTS` 的 `xPercent`（或等价：按 `progressStart`/`progressEnd` 中点换算），保证与区段空间对齐。
- **轴上标注：** 本地化 `period`（短时间文案）。
- **卡片内容：** 本地化 `era`、`period`、`desc` 全文；`pointer-events: none`。
- **上下交替：** 索引从 0 起，**偶数在轴上方，奇数在轴下方**（写死，不随语言变化）。
- 卡片宽度：约 `min(280px, 22vw)`；窄屏可 `line-clamp` 描述（建议最多 4～5 行），避免严重叠压；轻微半透明纸色底，不做成厚重仪表盘卡片。

### 3.3 与插画关系

- 黑线插画保持现有下移；时间轴叠在 lineart 之上（`z-index` 高于插画、低于未来若恢复的近景）。
- 不新增路/行人层。

---

## 4. 技术结构

### 4.1 数据

- 继续使用 `@/data/cultureScroll` 的 `CULTURE_SCROLL_SEGMENTS` + `CULTURE_SCROLL_HOTSPOTS`。
- 热点数据语义改为 **时间轴锚点**（可改名 `CULTURE_SCROLL_MARKERS`，非必须；若改名需同步测试）。

### 4.2 组件改动（`CultureScroll.vue`）

- 删除：hotspot `<button>`、scrim、dialog、相关 open/close/键盘 Esc 逻辑。
- 新增：中景内 `.culture-scroll__timeline`（线）+ 每个 marker 的节点 + 卡片。
- 时间轴容器与 mid 层同 `layerStyle(1)`，随卷移动。
- 保留：`activeSegment` 驱动左下角 colophon；当前区段对应节点可加轻微高亮（描边或点色加深），非必须但推荐。

### 4.3 测试

- 更新 `CultureScroll.spec.ts`：断言时间轴/卡片存在；不再断言可点热点与 dialog。
- 覆盖：至少渲染全部 segment 的 era；轴上出现 period。

---

## 5. 明确不做

- 卡片点击、跳转详情页、二次弹层
- 视口固定「当前一条」时间轴替代画中轴
- 3D / 重型时间轴库
- 改写 segment 历史文案内容（仅展示方式变化）
